# 数据浏览设计

> 后续修改数据记录、历史查询或曲线界面的 agents 请继续维护本文档，保证文档与程序实际行为一致。

## 1. 数据来源与存储

- 子板完成一次有效轮询后，`DataLogger` 立即记录一条 CSV；记录频率跟随参数页配置的轮询周期，默认周期为 1 秒。
- CSV 按天分文件，路径为 `dataPath/YYYY-MM-DD.csv`。
- 新 CSV 只保留无法从其他列还原的必要数据：ISO 8601 毫秒时间、RS485 端口、子站 ID、子板名称、三路温湿度、两路 PT100、外部电压和 OT1～OT6。平均值、报警状态、设定参数、指示灯和 JSON 都不重复保存。子板稳定唯一键是 portIndex + slaveId。
- 历史解析同时兼容旧六列 JSON 格式和新的精简列格式；升级当天若已有旧文件，继续按旧表头写入，次日自动启用新表头，避免一份 CSV 混用两套列定义。预留寄存器不再记录；当天旧表头的 reserved_input 列留空，历史查询忽略旧文件中的该字段。
- 文件在容量上限内全部保留，默认上限 12 GB；超限时从最旧文件开始轮转，不使用数据库。
- 记录周期和容量上限在参数页设置并保存。手动清理按天/月/年的时长计算截止日期，不要求操作员直接选日期。

## 1.1 文件管理

- 参数页每 10 秒刷新存储设备总量、可用空间、日志目录占用、CSV 文件数和日期范围，也可手动刷新。
- 操作员选择一个日期后，系统只匹配合法的 YYYY-MM-DD.csv，预览该日期之前的文件数量和容量，并在删除前二次确认。
- “之前”采用严格小于：选择 2026-09-01 不会删除 2026-09-01 当天文件；删除完成后刷新历史子板索引。

## 2. 子板筛选列表

历史页的下拉列表合并两类来源：

1. 本次运行已自动发现的子板。
2. `dataPath` 下 CSV 文件中出现过的端口和子站 ID。

因此，子板当前离线或尚未被自动扫描到时，仍可以查看它的旧数据。只存在于 CSV 的条目标记为“历史”，但不禁用选择。同一 ID 位于不同 RS485 端口时是两个独立条目。

CSV 子板索引只在进入数据浏览页时重载。自动发现列表变化时只合并内存数据，不重复扫描全部 CSV，避免大量历史文件导致界面卡顿。

## 3. 单块子板模式

选择具体的 `P端口 / ID` 后：

- 查询只返回该子板的记录。
- 曲线按通路分别画，不合并成一条平均温度；A/B/C 是三个独立的温度传感器，每个都出温度与湿度两条线：
  - A温度 / B温度 / C温度 三条**实线**，颜色分别为亮黄 / 绿 / 红（#ffd54f / #66bb6a / #ef5350）。
  - A湿度 / B湿度 / C湿度 三条**点线**，与同色温度靠线型区分；湿度也按通路画，不再取三路平均。
  - PT100 1 / 2 两条（棕色系深浅两档 #a1887f / #8d6e63，虚线与点划线）。
- 笔宽：温度实线 2px（主信号醒目），湿度点线与 PT100 1px（细，减少叠加时的糊成一团）。1px 的曲线关闭抗锯齿绘制——点线的每个点只有 1px 宽，开抗锯齿时几乎每个点都和图表底色混色，整条曲线会淡到看不见。
- 曲线上直接贴文字标签（A温度 / A湿度 / PT100 1 …），不记颜色也能读出哪条是哪条：标签锚定在该序列最右端的有效点，外框线型与曲线一致（温度实线、湿度点线），框内填图表底色保证文字可读；避让后标签可能离锚点较远，用同色引线连回曲线。多个标签按一维纵向避让排布，**框与框不互相遮挡**，且全部落在绘图区内。
- 某条序列是否存在、是否画出来，逐条记录判断，不读当前配置：未配置加热器的通路在 CSV 里本来就是空列（`DataLogger::appendRecord` 按 `heaterXPair` 是否为 0 决定是否记录），历史数据缺哪一路就自动不画哪一路，重新配置后旧数据也不会补出这条曲线。读数越界（温度 -40～85 ℃、湿度 0～100 %RH）同样不画，探头故障时不会拉崩纵轴。PT100 未接入读 0，按非零排除。
- 图例、曲线标签、十字线标记和数值提示都跟随实际画出的序列动态生成，不会出现对应没有曲线的空图例、空标签或“B温度 --”这类条目。数值提示的配色与曲线同一套。
- 表格显示该子板最新 500 条查询明细，其中温度列仍取三路均值（与旧行为等价）。

## 4. 全部子板模式

“全部子板”不直接把不同子板的点连成一条线，而是先按整秒聚合当秒可用样本：

- 每块子板先按通路聚合自身三路温湿度。
- A温度 / B温度 / C温度 三条实线各自显示当秒各子板该路温度的总体平均值（与单板模式同一套颜色）。
- A湿度 / B湿度 / C湿度 三条点线各自显示当秒各子板该路湿度的总体平均值。
- 半透明范围带显示当秒参与聚合的所有子板、所有通路温度的最低值到最高值。
- PT100 1 / 2 两条曲线各自显示当秒各子板该路 PT100 的总体平均值。
- 点击曲线时，详细信息同时显示温度范围和当秒参与聚合的记录数。
- 表格不做聚合，仍保留每块子板的原始明细，最多显示最新 500 条。

结果摘要分别显示“原始明细数”和“聚合时间点数”，避免将两者混淆。

## 5. 最新数据与历史拖动

- 日期或子板查询后，曲线默认定位到最新时间。
- 视图位于最右侧时，新记录会自动追加并跟随最新。
- 用户左右拖动查看旧数据后，新数据不抢回视图位置。拖回最右侧即恢复自动跟随。
- 已建立页面缓存且日期范围、子板筛选均匹配时，新写入的记录由 `recordAppended` 直接追加；即使当前切到其他页面也不需重新扫描 CSV。

## 5.1 实时数据模式

- 页面顶部“✓ 自检正常”左侧有一个同款外观的“实时数据”按钮，只在数据浏览页显示。
- 按下后进入实时模式：日期筛选被强制为今天并禁用（置灰），结果摘要改为“实时数据 · 最近 30 分钟 · N 个时间点”；再按一次退出，恢复进入前的日期区间并重新查询。
- 实时模式只保留最近 30 分钟的点（现场 1 秒一条，约 1800 个点），旧点由 `HistoryChart::trimRecords` 从图表和内存记录中一起裁掉；正在查看的十字线随记录一起左移，仍指着同一条读数，只有被裁掉的才重置。
- 跨零点不重新查询：新记录的日期与当前加载日期不一致时，直接跟着新的一天继续追加，画面不因换日而断。
- “查询”按钮在实时模式下仍然可用，作用是刷新这个实时窗口。

## 6. 页面缓存与读盘时机

- 程序启动时不立即查询历史数据，首次进入数据浏览页时才加载子板索引和当前查询条件。
- 查询结果、聚合曲线和最新 500 条表格明细保留在内存中。切换到其他页后，新写入记录仍按当前日期/子板条件增量更新该缓存。
- 再次进入数据浏览页直接显示缓存，不重读 CSV。
- 日期或子板条件改变后点击“查询”才重新读取匹配文件。相同条件重复点击“查询”只恢复跟随最新，不重复读盘。

## 7. 触摸屏交互

- 水平时间滚动条高度为 36 px，拖块最小宽度为 100 px。
- 子板下拉列表最多同时显示 7 项，使用 36 px 宽的竖向触摸滚动条。
- 曲线支持拖动时间轴与点击查看交叉线详情。
- “仅看表格”用于小屏幕上将空间集中给明细数据。
- “实时数据”按钮与自检 pill 同款外观（圆角、字重、内边距一致），位于其左侧；开启时用蓝色而非自检正常的绿，避免两个 pill 颜色相近被误读。

## 8. 性能边界

- CSV 子板索引只解析身份列，不解析旧格式 JSON 或新格式测量列，用于减少进入页面时的成本。
- 当前历史查询仍会将日期范围内的匹配记录读入内存，表格虽只显示 500 条，但曲线保留全部查询点。在 1 秒周期、多子板和长日期范围组合下，后续需考虑流式聚合或曲线降采样，避免内存随记录数线性增长。
