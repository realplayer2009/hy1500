# 温湿度探头地址切换

本文件夹包含现场探头的 Modbus 地址配置记录和地址检测/修改脚本。

## 文件

- `湿度探头地址工具.py`：扫描、读取温湿度，以及修改并验证设备地址。
- `湿度探头_Modbus_ID配置记录.md`：现场串口参数、报文和地址从 1 改到 3 的验证记录。
- [郎汉德 LH-TH 系列温湿度传感器说明书（官方 PDF）](https://www.lonhand.com/uploads/20230828/b92d6ca7c1689e195354c2fc03e3ca9e.pdf)：包含寄存器表和地址修改报文示例。

## 通信参数与地址寄存器

脚本使用 9600 bps、8N1，默认串口为 `/dev/ttyUSB1`。地址写入寄存器 `0x0100`，使用 Modbus 功能码 `0x06`；温湿度从 `0x0000` 起读取，原始数值除以 10。

手册标注 9600 bps 为出厂默认值，但它列出的波特率代码是 `3`；现场配置记录读到的代码是 `4`。脚本只使用 9600 bps 通信，不修改波特率寄存器。

## 使用

先安装依赖：

```bash
python3 -m pip install pyserial
```

扫描 1～247 地址：

```bash
python3 湿度探头地址工具.py scan
```

读取地址 1 的探头：

```bash
python3 湿度探头地址工具.py read 1
```

把地址 1 改为 3：

```bash
python3 湿度探头地址工具.py change 1 3
```

串口不是默认值时，把 `--port 串口名` 放在子命令前，例如：

```bash
python3 湿度探头地址工具.py --port /dev/ttyUSB0 scan
```

改地址前请确保总线上只有一只待配置探头。脚本会检查目标地址是否已占用，并在写入后分别验证新地址和旧地址。
