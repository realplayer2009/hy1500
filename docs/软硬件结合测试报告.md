## 三、软硬件结合点（本轮重点）

1. **安装通道**：CI 产物经 `adb install --no-streaming -r` 落屏。`--no-streaming` 是必须的——流式安装实测会把 `libRS485Control_arm64-v8a.so` 写坏（ELF magic 变 `00000000`），装完能启动但一调 native 就崩。2 台均读回 magic 验证。
2. **配置属主**：`app.ini` 必须由应用（app uid）持有。用 `su 0 cp` 写入会变成 `root:root`，应用之后写不回配置，现场改参数存不住且不报错。2 台均 chown 回应用 uid 并读回确认。
3. **界面实测 ↔ 无头断言互证**：呼吸灯为真渐变（连抓 8 帧，绿色像素 308→272→216→52→44→32→44→52 走完一个周期）；手动模式"● 手动模式"红底 500 ms 严格交替；总览告警 `⚠` 前缀同步交替——与 `feature_test` 的无头断言互相印证。
4. **换签名部署**：装机方预装版本与 CI 产物签名不同（实测本地构建与 CI 为**同一把 key**，sha256 前 24 位均 `E7:5F:13:A9`），且该应用是设备所有者、连卸载都被禁。已跑通"备份 → 解除设备所有者 → 重启 → 卸载 → 装新包 → 还原历史数据 → 恢复装机状态"全流程，2 台实测通过。
