| K1 / K2 | 测控带电监测（遥信） | XT-16 / XT-15 |
| K3 / K4 | 电磁锁控制 | XT-12 / XT-11 |

### 1.4 电磁锁带电闭锁回路（原设计核心）

```
ZKK3-2 ──XT-11──► K4 ═══[带电显示器内部接点]═══ K3 ──XT-12/XT-17──► A/B/C 相电磁锁 L
ZKK3-4 ───────────────XT-20────────────────────► A/B/C 相电磁锁 N
```

即：**带电显示器的 K3/K4 接点串联在电磁锁供电回路里**。带电时接点断开 → 电磁锁失电；
停电时接点闭合 → 电磁锁得电。所以现场的电磁锁必须是**失电闭锁型**。

### 1.5 图内其他内容

- A/B/C 相保护跳闸 TH:N1 / N2 / N3 / N4

## 二、博峰 BDXN3 电气接口（新带电显示器）

### 2.1 型号与额定

| 型号 | 类型 | 说明 |
|---|---|---|
| BDXN3T | 提示型 | 只有显示 |
| BDXN3Q | 标准型 | 显示 + 闭锁接点 |
| BDXN3 | 智能型 | 显示 + 闭锁接点 + 可选通讯 |
| BDXN3H | 智能型 | 同上，另带核相孔 |

额定电压 6 kV(7.2) / 10 kV(12) / 35 kV(40.5)。

### 2.2 控制器端子（9P）

| 端子 | 功能 |
|---|---|
| L+、N、− | 工作电源，85~265 VAC / 100~360 VDC |
| K1、K2 | 电磁锁1 闭锁接点 |
| K3、K4 | 电磁锁2 闭锁接点 |
| K5、K6 | 微机五防接点 |
| A、B、C | 三传感器输入（屏蔽线，出厂已接传感器端） |
| 接地 | 就近接地 |
| 外置 4.5 VDC 插口 | 备用电源（3 节 5 号电池，>72 h） |

闭锁接点容量 5 A / 250 VAC / 30 VDC；响应时间 ≤1 s；整机功耗 <2 W；防护 IP4X。
装箱含控制器 1、传感器 3（黄/绿/红 5 m 屏蔽线）、支架 2、接线端子 2（8P、9P 各一）。

### 2.3 输出接点状态表（本方案的安全依据）

| 接点 | 母排带电 | 母排不带电 | 装置无工作电源 |
|---|---|---|---|
| K1、K2 | **断开** | 闭合 | 断开 |
| K3、K4 | **断开** | 闭合 | 断开 |
| K5、K6 | **闭合** | 断开 | 闭合 |

注意 K5/K6 与另两对**极性相反**，且装置失电时也保持闭合——它表达的是「五防允许操作」，
不能用来判断「是否带电」。**判断带电只能用 K1/K2 或 K3/K4。**

### 2.4 安装约束（摘自说明书）

- 控制器与电磁锁等电磁元件距离 **≥200 mm**
- 传感器与柜内电压/电流互感器距离 **>250 mm**
- 传感器与母排空气距离：6 kV 100~120 mm、**10 kV 125~145 mm**、35 kV 300~320 mm
- 三个传感器须在同一直线上且垂直于母排轴心，相互偏差 **±5 mm**
- 相间距一致；采用复合绝缘时相间净距不小于 70 mm
- 传感器屏蔽线**不得从中间断开或经中间端子对接**，应连续引至控制器
- 控制器接地端子引至最近接地点直接接地

### 2.5 通讯：说明书没有协议

说明书的「通讯协议」章节只有一句「协议可在订货时索取」，
**本说明书内没有任何 RS485 / ModBus-RTU 协议内容**。这是集成的关键缺口，见第五节。

## 三、YTT-1500 现有能力（改造后的温湿度控制装置）

硬件 = PA0715-N 触摸屏（RK3562 / Android 13 / 1024×600 / 开放 root）+ 域控主板 V-1.1。
板上接口：温湿度传感器接口（B2−/GND/A2+/V0+）、PT100 接口（B3−/GND/A3+/V0+）、OT1~OT10、DIP 1~4。

| 能力 | 现状 |
|---|---|
| 加热器 | 三路 A/B/C，各一对 OT 驱动；低位=1 档、高位=2 档、同开=3 档。`heaterAPair/heaterBPair/heaterCPair`，0=未配置，1=OT1+OT2 … 5=OT9+OT10 |
| 测量 | 三路温湿度 th1/th2/th3、两路 PT100、外部电压 |
| 通讯 | 两路 RS485；现场 Port0=`/dev/ttyS4` 挂域控主板，Port1=`/dev/ttyS2` 备用。Modbus ID 1~247，每口最多 16 块 |
| 外扩输入 IN1~IN5 | 实际地址 **0x000C**（bit0~bit4；协议文档写的 0x000E 在现场 firmware 上恒为 0，仅作旧 firmware 回退）。可分配 未使用 / 手动自动 / 加热A / 加热B / 加热C / 高压闭锁 |
| 外扩输出 OUT1~OUT7 | 写 **0x0033**（bit0~bit6）。OUT1~OUT3 加热器工作灯、OUT5 操作提示蜂鸣器、OUT6/OUT7 扩展指示均为只读；OUT4 备用扩展输出保留手动入口 |
| OT 位掩码 | **0x0031**，RMW 写入（保留报警灯等位） |
| OT9 / OT10 | 红色报警灯 / 高压报警蜂鸣器，程序自动驱动，只读 |
| 高压联锁 | 数字量读 `0x0001`（可配 0/1 触发）或模拟量读 `0x0003`（原始值÷10 与 `highVoltageThreshold` 严格高于比较）。默认模拟量 + 5.0 V |

## 四、旧设备 → 新设备的接口映射

原图只有「旧带电显示器的 L/N/K1~K4」和「旧温湿度控制器的 12 个端子」。
BDXN3 的 9P 端子与旧设备**不是一一对应**，映射如下：

| 原端子 | 原用途 | 改造后接往 | 说明 |
|---|---|---|---|
| XT-9 / XT-10 | 带电显示器 N / L | BDXN3 N / L+ | 电源规格相同（AC220，取自 ZKK2），可直接沿用 |
| XT-11 | 电磁锁控制（ZKK3-2 来） | BDXN3 **K2** | 电磁锁1 的入口 |
| XT-12 | 电磁锁控制（去 XT-17） | BDXN3 **K1** | 电磁锁1 的出口，复现原 K3/K4 功能 |
| XT-15 / XT-16 | 测控带电监测 | BDXN3 **K6 / K5** | 送微机五防 |
| XT-1~XT-8 | 加热器/传感器 | YTT-1500 域控主板 | 见 5.3 |
| XT-13 / XT-14 | 温湿度电源 | YTT-1500 工作电源 | |
| XT-17~19 | 电磁锁火线 | 三相电磁锁 L | 保留 |
| XT-20~22 | 电磁锁零线 | 三相电磁锁 N | 保留 |
| （无） | — | BDXN3 **K3/K4** | 电磁锁2，留作备用 |

**关键差异**：旧设备用 K1/K2 做「测控带电监测」、K3/K4 做「电磁锁控制」；
BDXN3 把「电磁锁1」放在 K1/K2、「微机五防」放在 K5/K6。
所以原 K1/K2 的监测功能**没有直接对应的同极性接点**——K5/K6 极性相反且失电也闭合，
只能当「五防允许操作」用，不能当「带电判据」。

## 五、两个必须先解决的缺口

### 5.1 YTT-1500 的「高压闭锁」映射目前没有逻辑

外扩输入可以把某一路 IN 配成 `hv_lockout`（高压闭锁），
但代码里**只有下拉标签和显示，没有任何控制分支**（AGENTS.md 亦记载「高压闭锁映射仍仅用于显示」）。
也就是说「BDXN3 接点 → IN 口 → 高压联锁」这条路**现在走不通**，
要先在程序里补：IN 判定为高压闭锁时的联锁动作（至少应覆盖三路加热器输出对与工作灯，
与现有模拟量/数字量联锁同一套关断逻辑）。

### 5.2 BDXN3 的 RS485 协议没有提供

说明书明确协议「可在订货时索取」，但**正文里没有**；YTT-1500 程序里也没有 BDXN3 驱动。
所以本方案**不依赖通信**，全部用无源接点硬接线实现。
若后续想要读到 BDXN3 的带电状态/传感器数据，需先向福州博峰索取协议，再开发驱动。

## 六、整体解决方案（推荐）

### 6.1 电源

三路电源完全沿用原设计，只是负载换了：

- ZKK1 → YTT-1500 工作电源（XT-13/14）
- ZKK2 → BDXN3 工作电源 L+/N/−（XT-9/10）。BDXN3 宽电压 85~265 VAC，直接可用
- ZKK3 → 电磁锁回路（XT-17 火线 / XT-20 零线）

### 6.2 电磁锁带电闭锁（复现原 K3/K4 功能）

```
ZKK3-2 ──XT-11──► K2 ═══[BDXN3 电磁锁1 接点]═══ K1 ──XT-12/XT-17──► A/B/C 相电磁锁 L
ZKK3-4 ─────────────────XT-20────────────────► A/B/C 相电磁锁 N
```

带电时 K1/K2 断开 → 电磁锁失电闭锁；停电时闭合 → 得电可操作。
**前提：现场电磁锁必须是失电闭锁型**（原设计就是这样，换 BDXN3 后接点极性未变，可沿用）。
若现场实际是得电闭锁型，则改接 K5/K6（带电时闭合），但那样装置失电时会误闭合，需评估。

### 6.3 微机五防

BDXN3 K5/K6 → XT-15/16 → 微机五防/测控。取代原「测控带电监测」。
注意它只在「不带电」时断开，适合做「允许操作」信号，**不要当带电判据用**。

### 6.4 备用

BDXN3 K3/K4（电磁锁2）留空，作为第二套闭锁回路备件；
若要驱动第二级联锁（如另一柜），从 XT 备用位引出。

### 6.5 温湿度与加热器（YTT-1500）

- 加热器 A/B/C 各占一对 OT，按现场实际路数配置 `heaterAPair/heaterBPair/heaterCPair`
  （0=该路没有加热器）。原图只有 2 路加热器，YTT-1500 支持 3 路，第 3 路是新增能力
- 温湿度三路 + PT100 两路按接口定义接入域控主板
- 外扩输入按现场防错线排查结果分配：拨动开关看哪个 IN 在跳，就把实际功能分配给该 IN
  （`expIn1Mode`~`expIn5Mode`：未使用/手动自动/加热A/加热B/加热C/高压闭锁）
- OUT1~OUT3 接加热器工作灯，OUT5 接操作提示蜂鸣器，OT9 接红色报警灯，OT10 接高压报警蜂鸣器
- 高压联锁沿用模拟量读 `0x0003` ÷10 与阈值比较（默认 5.0 V），或按现场传感器改成数字量 `0x0001`

### 6.6 BDXN3 传感器

- 三相传感器按 10 kV 取 **125~145 mm** 空气距离（若现场是 6 kV 或 35 kV，按 2.4 节改）
- 三个传感器同一直线、垂直于母排轴心，相互偏差 ±5 mm，相间距一致
- 与柜内互感器距离 >250 mm；控制器与电磁锁 ≥200 mm
- 屏蔽线连续引至控制器，不经中间端子；控制器接地端子就近直接接地

## 七、现场需确认的开放问题

1. **电磁锁是失电闭锁还是得电闭锁？** 决定用 K1/K2 还是 K5/K6。（原图接线方式暗示失电闭锁，需现场核实）
2. **厂高变额定电压是多少？** 决定 BDXN3 型号（6/10/35 kV）与传感器安装距离。
3. **BDXN3 具体订的哪个型号**（T/Q/智能型/H）？只有智能型才有 RS485，也才有后续通信集成的可能。
4. **要不要把 BDXN3 的带电状态送进 YTT-1500 参与高压联锁？** 若要，先补 5.1 的程序逻辑。
5. **要不要向博峰索取 RS485 协议？** 索取后才能做通信集成（5.2）。
6. **现场有几路加热器/温湿度探头？** 决定 `heaterXPair` 与温湿度通路配置（原图 2 路，YTT-1500 支持 3 路）。
7. **外扩输入 IN1~IN5 实际接了什么？** 需在现场拨动开关排查后分配。
8. **域控主板串口**：现场 RS485 实际挂 `ttyS4`（规格书写的 COM1=ttyS01 是错的），换屏或重烧系统后须重新核对。
